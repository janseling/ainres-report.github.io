API · 字段说明

全部数据公开 · 静态 JSON · 浏览器直取即可（GitHub Pages 默认允许跨域；无鉴权、无配额）

端点一览

/reports/index.json期清单：id / date / time / title / itemCount / coverage / overview…（新→旧）
/reports/archive.json归档富索引：期清单再加 hl（头条 3 条 + 对应条目锚点 a）、conf（高/中/低计数）、verify（多源佐证率）
/reports/<id>.json单期全量数据（字段见下）
/reports/<id>.html单期分享页（静态直出，含 og 元信息，微信等爬虫可读）
/report.html?id=<id>期报 SPA 视图（与静态页共用同一渲染器）
/rss.xmlRSS 2.0 订阅，最新 20 期，随发布自动更新
#id 锚点期报页条目锚：reports/<id>.html#it-<板块>-<序号>，可直达单条（如 #it-product-0）

期报 JSON 字段

coverage采集窗口（Asia/Shanghai 绝对时间）
overview[]速览行（可含 markdown 链接）
sections[].items[]条目数组；sec.key ∈ product / tech / policy / industry（行业板块内含安全内容）
item.title / urls[]标题 + 原文链接（urls[0]=主链）
item.meta来源 · 披露时间 · 事件时间（单行元信息）
item.publish_time / event_time披露时间 / 事件时间；event_time_inferred=事件时间为推断（true 时标 ~ 与「推断」）
item.type_tags[]类型徽章（💰 商业 / 🛠 产品 / ⚡ 技术 / 🏛 政策 / 🛡 安全）
item.confidence置信度：高 / 中 / 低；confidence_note 佐证口径（如「多源同报」）
item.source_tier信源分级 A 官方源 / B 主流媒体源 / C 聚合源 / D 社区源
item.summary摘要（≤60 字，实体名词后续接入内联导航）
item.angles[]观点角度（kind: invest/startup/tech/opinion；每条 0~2 行）
item.verify_note外部佐证（同报媒体的链接说明）
item.snapshot原文快照：file 路径 + sha256 前缀指纹
item.provenance溯源：raw_ref（raw JSON 路径 #candidates[n]）/ source_id / source_name
item.original_title源站原题（与定稿标题不同时给出）
signals[]跟踪信号：lead 一句 + text 详情（SIG 台账兑现机制的数据源）
rawStats采集统计：candidates 候选扫描量 / selected 入选数

骨架合同（每条 News 七元素，渲染器照单全收）

① 标题＋原文↗　② 元信息（来源·披露·事件时间）　③ 徽章排　④ 摘要≤60字　⑤ 观点角度 0~2 行　⑥ 佐证行　⑦ 证据链折叠

示例

curl -s https://ainews.im-max.com/reports/index.json | jq '.reports[0]'
curl -s https://ainews.im-max.com/reports/2026-10-10-2100.json | jq '.sections[].items[].title'
curl -s https://ainews.im-max.com/reports/archive.json | jq '.reports[0].conf'
时间口径：一律 Asia/Shanghai；事件时间早于披露时间（≤硬约束）；推断时间带 ~ 标注。
