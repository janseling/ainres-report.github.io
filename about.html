01定位与目标

AI 领域每天产生海量信息：官方发布、媒体解读、社区传言、政策文件混杂在一起，二手摘要经常失真。AI 情报日报以每天 09:00 / 15:00 / 21:00 三场的固定节律，把最近数小时内的关键动态定稿成可溯源条目：每条附原文链接，重要事件聚合多个独立信源同报，并持续跟踪后续走向。每期由 Agent 自动采集定稿。

服务对象是创业者与决策者——需要的不只是「发生了什么」，还有信息可信度与后续走向。

02数据源

信源按层级组织，官方一手博客优先，媒体与社区做交叉补充：

  • 官方博客（一手源）：OpenAI、Google DeepMind、Anthropic、NVIDIA、Hugging Face、arXiv、DeepSeek、阿里千问、MiniMax 等，发布当日必查。
  • 国际媒体：TechCrunch AI、Ars Technica、The Verge、Hacker News、Simon Willison、Reddit（r/LocalLLaMA 等）、GitHub Trending、Product Hunt。
  • 国内媒体：量子位、极客公园、爱范儿、少数派、36 氪 AI、智东西、甲子光年，以及机器之心 / 新智元的官方认证同步号。
  • 政府与智库：网信办、国务院政策库、中国信通院、工信部。

03聚合规则

  • 多源同报：同一事件被多个独立信源报道时，聚合为一条条目，全部原始链接保留在条目证据链中。
  • 单源标注：仅单一信源的事件单条收录，口径注明。
  • 信号追踪：需要持续观察的事件登记为「信号线」，每条线持有溯源档案号（SIG-日期-场次-序号）。之后每期回访，直至到达检查节点 check——预期的验证日，到点核查并给出「已兑现 / 已证伪 / 继续跟踪」结论。

04佐证与可信度

每条目标注置信度：高 / 中 / 低，由独立信源交叉程度决定；口径写入 confidence_note（如「多源同报」），外部佐证写入 verify_note。期级 verify.rate 为该期条目获外部独立佐证的比率。

字段与口径明细见 API · 字段说明。判断不隐藏——每条都能点回原文自行核验。

05开放数据

全部数据零权限直接拉取：API 与字段说明 · RSS · archive.json（归档富索引）· topics.json（信号线台账）。欢迎接入你自己的 Agent 或推送管道。
